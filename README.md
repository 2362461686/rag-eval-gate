# rag-eval-gate

把 RAG 的检索质量变成能进 CI 的回归门禁，并且**先评测评测器本身**：门禁能拦住什么、拦不住什么、会不会误报；幻觉检测器到底比一个简单基线好多少。

全部在 CPU 上运行，不调用任何付费 API。数字都来自 [`results/`](results/)，结果不好的也照实写。

## 结论

1. **门禁拦得住实质回归，也有明确的盲区。** 注入 16 类故障，拦下 7 类，其余逐项归因：3 类三项指标都上升，5 类跌幅低于门限，1 类不显著。4 个无害调参 0 误报，零假设模拟误报率 3.0%（9/300）。
2. **“看起来是 bug”不等于“指标会变差”。** 把 RRF 平滑常数置 0、召回深度降到 10，在 SciFact 上三项指标反而上升；TopK 少返回一条，指标几乎不动。指标门禁替代不了契约测试。
3. **轻量 NLI 接地检测没有赢过词面基线。** 留出测试集 AUC：NLI 0.728，词面重合 0.766，95% 区间不重叠。
4. **F1 会骗人。** Data2txt 上两种方法 F1 都约 0.78，但 AUC 只有 0.51，基本是随机排序；高 F1 来自 64% 的正例率。跨模型同理：NLI 在 GPT-4 上 F1 0.28、Mistral-7B 上 0.79，AUC 却只差 0.07。

## 检索回归门禁

数据：BEIR SciFact 测试集，5,183 篇文档，300 条查询。指标按 trec_eval 口径实现，并与 `pytrec_eval` 做差分校验。

| 检索方式 | nDCG@10 | Recall@10 | MRR@10 |
|---|---|---|---|
| BM25 | 0.6652 | 0.7833 | 0.6349 |
| BGE 向量 | 0.6948 | 0.8162 | 0.6633 |
| RRF 混合（基线） | 0.7038 | 0.8271 | 0.6695 |

**判定规则**：对每个指标做配对符号翻转检验（单侧），三个指标 Holm 校正，同时给 Bootstrap 95% 置信区间。任一指标满足 `p_holm < 0.05` 且 `delta <= -0.01` 即判回归。

```console
$ python -m ragate.gate results/runs/baseline.json results/runs/candidate_silent_fallback.json
REGRESSED mrr@10     0.6695 -> 0.6349  delta -0.0346  95% CI [-0.0596, -0.0103]  p_holm 0.0070
REGRESSED ndcg@10    0.7038 -> 0.6652  delta -0.0385  95% CI [-0.0608, -0.0161]  p_holm 0.0015
REGRESSED recall@10  0.8271 -> 0.7833  delta -0.0438  95% CI [-0.0766, -0.0121]  p_holm 0.0070
```

退出码：0 通过，1 回归，2 输入非法。

### 误报与灵敏度

- 无害调参（BM25 k1=1.5、b=0.7，RRF k=50，召回深度 200）：0/4 误报。
- 零假设模拟：对真实的逐查询差值随机翻转符号，300 次中误报 9 次（3.0%），名义水平 5%。
- 随机丢文档的检出率（每档 20 个随机种子）：

| 2% | 10/20 | -0.0167 |
| 5% | 19/20 | -0.0394 |
| 10% | 20/20 | -0.0740 |
| 20% | 20/20 | -0.1510 |

## 幻觉检测器评测

数据：[RAGTruth](https://github.com/ParticleMedia/RAGTruth) 的人工标注，回答来自数据集中的 6 个模型（GPT-4、GPT-3.5、Mistral-7B、Llama-2 7B/13B/70B），不是本项目调用生成。只保留 quality=good 的样本。

方法：回答切句，每句到证据里取词面重合最高的 3 个窗口（60 词，步长 30），做 NLI 蕴含；回答分 = 1 − 最弱句的支持度。词面基线直接用句子词在证据中的覆盖率。

流程：阈值只在随机抽取的 3,000 条训练样本上定，2,675 条测试样本只报告一次，不回头调模型或窗口。

| 方法（测试集，正例率 35.3%） | Precision | Recall | F1 [95% CI] | AUC [95% CI] |
|---|---|---|---|---|
| 全判幻觉（平凡基线） | 0.353 | 1.000 | 0.521 | 0.500 |
| NLI 句级接地 | 0.466 | 0.889 | 0.612 [0.591, 0.632] | 0.728 [0.708, 0.747] |
| 词面重合基线 | 0.527 | 0.836 | 0.647 [0.623, 0.669] | 0.766 [0.748, 0.784] |

### 其他观察

- **阈值不能跨任务通用。** 词面基线用 QA 校准的阈值去判 Summary，F1 0.298，用 Summary 自己校准是 0.415。NLI 的阈值在三个任务上分别是 0.967、0.993、0.490。
- **定位到句子更难。** 句级（17,519 句，正例率 8.8%）NLI F1 0.238、AUC 0.689；词面 F1 0.267、AUC 0.732。
- **标注口径敏感性。** 去掉 implicit_true 和 due_to_null 的标注后，AUC 分别为 NLI 0.710、词面 0.741，结论方向不变。

## 局限

- 检索只跑了一个数据集，300 条查询的功效有限：只丢 1% 文档时检出率 3/20。
- 故障是配置级模拟，不是线上真实事故；门禁是单侧的，只拦变差，不提示“变好”。
- NLI 只测了一个量化的 xsmall 模型，不代表 NLI 方法整体，也没有跑 LLM 裁判或 GPU 大模型。
- RAGTruth 的回答来自 2023 年前后的模型，分布不等于今天的生产流量。
- 窗口、取 3 个窗口等参数是预先定的，没有网格搜索。

## 工程验证

- 136 条 pytest 单测，指标与 `pytrec_eval` 差分校验，符号翻转检验与精确枚举对比。
- AST 突变测试：179/179 拦截，另排除 2 个等价突变（`tools/mutate.py`，覆盖比较、布尔、算术、取反、一元负号、数字常量）。排除的 2 个是已证明不改变行为的等价突变，理由写在脚本里。
- CI（`.github/workflows/ci.yml`）跑单测、突变，并用 `results/runs/` 验证门禁放行未改动的版本、拦下静默降级；CI 不下载模型和数据。

## 复现

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-experiments.txt   # 只跑测试和门禁用 requirements.txt
pytest -q
```

数据和模型放在仓库外，目录结构：

```text
$DATA/scifact/scifact/{corpus.jsonl,queries.jsonl,qrels/}   # public.ukp.informatik.tu-darmstadt.de/thakur/BEIR/datasets/scifact.zip
$DATA/ragtruth/{response.jsonl,source_info.jsonl}           # github.com/ParticleMedia/RAGTruth 的 dataset/
$DATA/models/bge/{model_quantized.onnx,tokenizer.json}      # Xenova/bge-small-en-v1.5 @ ea104dacec62c0de699686887e3f920caeb4f3e3
$DATA/models/nli/{model_quantized.onnx,tokenizer.json,config.json}  # Xenova/nli-deberta-v3-xsmall @ 2a4f614a701367a02d51389039afc998faeda637
```

ONNX 模型取各仓库的 `onnx/model_quantized.onnx`。

```bash
export OMP_NUM_THREADS=6 PYTHONPATH=.:experiments
python experiments/run_retrieval.py --data $DATA/scifact --models $DATA/models --threads 6
python experiments/run_faithfulness.py --data $DATA/ragtruth --model $DATA/models/nli --threads 6
python experiments/analyze_faithfulness.py
```
